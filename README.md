# KOZA Support

KOZA Hamilelik Takibi için bağımsız destek sayfası.

## Yerel önizleme

```bash
python3 -m http.server 4173
```

Ardından `http://localhost:4173` adresini açın.

## Yayınlama

Site bağımlılıksız statik HTML, CSS ve JavaScript kullanır. GitHub Pages üzerinde doğrudan yayınlanabilir.

Resmi KOZA Gizlilik Politikası ve Kullanım Koşulları footer bağlantılarında ayrı sayfalar olarak sunulur.
